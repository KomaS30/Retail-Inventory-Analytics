# Retail-Inventory-Analytics# Retail Inventory Analytics

## Project Overview

This project focuses on analyzing retail inventory data using Python and Google Colab. The objective is to identify sales trends, monitor stock levels, evaluate supplier contributions, and generate business insights that support effective inventory management.

## Objectives

* Analyze category-wise sales performance
* Identify products approaching reorder levels
* Evaluate supplier contribution and dependency
* Understand inventory distribution across categories
* Generate actionable business recommendations

## Dataset Information

The dataset contains:

* 1000 inventory records
* 11 columns including product details, supplier information, stock levels, and sales data

Key attributes:

* Product ID
* Product Name
* Category
* Supplier Name
* Unit Cost
* Retail Price
* Opening Stock
* Units Sold
* Closing Stock
* Reorder Point
* Stock Status

## Key Insights

* Toys & Games emerged as the highest-selling category.
* Clothing category recorded comparatively lower sales.
* Several products require immediate stock replenishment.
* High-demand products need higher safety stock levels.
* Supplier dependency risks were identified.

## Business Recommendations

* Replenish low-stock products promptly.
* Maintain safety stock for fast-moving products.
* Monitor supplier concentration risks.
* Improve inventory planning using sales trends.
* Implement regular inventory performance tracking.
